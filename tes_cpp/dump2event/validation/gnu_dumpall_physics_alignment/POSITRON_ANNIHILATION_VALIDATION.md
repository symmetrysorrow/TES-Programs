# Positron annihilation validation

Earlier raw-only analysis of the official Windows Dumpall for the 2 MeV thick-Pb, 1,000-history case identified 103 pair-production candidate records and 102 annihilation candidate records. The annihilation signature included two live photon children and a dead positron archival child. This establishes candidate raw signatures in that different, parseable dataset; it does not map a new internal score-addition ID.

The current GNU 20-history files cannot be parsed past NCOL=4, so 0 positron additions were matched to internal diagnostic values in this run. The source diagnostics and raw-only historical candidate counts must not be mixed as if they came from the same execution or identifiers. No rest-mass energy or annihilation energy was newly scored or implemented.
