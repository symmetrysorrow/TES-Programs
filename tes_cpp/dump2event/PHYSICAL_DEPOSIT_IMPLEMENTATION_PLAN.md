# PHITS 3.341 エネルギー付与再構成：実装計画

**状態：研究用・段階的導入。現行 converter の E_deposit 算出式は変更しない。**

ベース：PR #6 の固定コミット 36dec9f139918d233faf0876736f43d1bbdb965c。
この実装ブランチは PR #6 の Draft 状態を維持し、既存ブランチに変更を加えない。

## 1. 検証済みと未検証の境界

以下はユーザーがローカル PHITS 3.341 診断実行から報告した結果であり、GitHub CI で再実測したものではない。

- Pb region 1000、100履歴の [t-deposit] タリー加算は38,077件。
- 通常電子 NCOL=14：37,190件。
- 電子停止 NCOL=11：727件。
- dead 二次電子の局所付与：30件。
- 厳密なゼロ加算：130件。
- 生 Dumpall と別途用意した PHITS 3.341 停止能テーブル・材料対応を使い、全38,077加算を最大差 5.81e-15 MeV で再現したとの報告。
- 別 seed の1,000履歴では正付与58履歴を再現したが、3履歴に隣接ヒストグラムビンへのずれが残る。
- C++ 試作はローカルで Windows コンパイラ子プロセスの起動障害 0xC0000139 により未検証。
- 光子・陽電子・材料境界・細かな voxel への一般化と、輸送区間内の微視的な空間付与分布は未証明。
- 過去の GNU ASCII Dumpall には80文字切り詰めがあった。ローカルの修復実験結果があるが、元の損傷ファイルを自動修復できるとは主張しない。

**停止能や材料マップは標準 Dumpall 単独には含まれない。正確な方式名は「Dumpall＋PHITS物理設定による再構成」。**

## 2. 実装順序と停止条件

### Gate 0：データの来歴と試験可能な契約

現行の PR #6 を変更せず、ローカルの停止能テーブル、領域・材料対応、カットオフ条件、PHITS/EGS5 バージョン、実行ファイルと入力 Dumpall のハッシュを記録する。これらの不一致、欠落時は fail-closed とする。PHITS配布ソース・大容量 Dumpall・専有停止能データを公開しない。

**このブランチで実装済み：** validation/compare_physical_deposits.py

これは PHITS 内部の実測タリー台帳と、内部実測値を入力とせず再構成した台帳とを、同一の確定タリー加算IDで照合するツール。次を検査する。

- ID の欠落・追加・重複
- エネルギーの NaN/Inf、負値、絶対誤差
- 任意指定した履歴ID・計上領域・スコア座標の差
- 履歴ごとの合計誤差と全体合計
- 厳密なゼロ加算の件数

エラー終了コード：0＝一致、1＝値・対応の不一致、2＝入力が不正。

このツール自体は物理計算を実施しない。数値が一致しても輸送区間内の微視的な分布を証明したことにはならない。エネルギーや座標の近さから ID を捏造してはならない。

既存ローカル CSV の列名が異なる場合、値を変更せずに一意な addition_id、event_id、region、x/y/z を共通化したエクスポートを作成する。

使用例（両 CSV に上記共通キーが存在する場合）：

    python tes_cpp/dump2event/validation/compare_physical_deposits.py reference.csv reconstructed.csv \
      --key-column addition_id \
      --reference-energy-column tlv \
      --candidate-energy-column E_deposit \
      --history-column event_id --region-column region \
      --position-columns x y z \
      --energy-abs-tol 1e-12 --json-report comparison.json

Windows PowerShell ではコマンドを1行にするか、適切な行継続記号を使用する。

合成テスト：

    python -m unittest discover -s tes_cpp/dump2event/tests -p test_physical_deposit_comparator.py -v

### Gate 1：Dumpall パーサを物理計算から分離

PR #6 の状態機械は、報告された実際の Dumpall の単一値 NZST や NCOL=10 の状態遷移で停止した。正常終端を持ち、80文字切り詰めを解消した入力を対象に、現物のレコード仕様と照合して構造的に修正する。合成テストだけでの成功を合格としない。

**合格：** 100履歴と10,000履歴を最後までストリーミング解析、レコード・反応数と終端一致。欠損ファイルは入力行番号付きでエラー。監査モードの結果を保持。

### Gate 2：証明済みの EGS5 電子付与のみを試験モードで移植

実験用 C++ の数値式そのものをローカルから取得してレビューする。報告値だけから数値式やテーブルを想像して実装しない。

- 37,190件の通常電子 NCOL=14 は PHITS 3.341 の停止能・輸送長・エネルギー更新を忠実に再現。
- 727件の NCOL=11 電子停止は、報告された Pb 検証条件での Eraw + stopping_power(Ecut, Pb) × chord の適用条件をコードで確認。
- dead 二次電子30件は QCLUSTS(7) をスコアし、継続輸送分との二重計上を避ける。
- ゼロ寄与130件は、入力が物理的にゼロであると示せるときのみゼロで記録。
- 物理過程 ID、履歴 ID、元 Dumpall の参照、計上領域、代表座標と輸送区間端点を保持し、未確認過程を未解決として残す。
- E_deposit をクリップしない、恣意的に再分配しない、総エネルギーを後付けで正規化しない。
- 物理モードを明示的に選択させる。現行の PR #6 のデフォルト出力は変更しない。

**合格：** 同一診断計算で38,077件すべての増分が許容差1e-12 MeVで一致し、履歴・領域・座標も合致する。重複計上0件。未解決量は件数とMeVの両方で開示。

### Gate 3：独立 seed、履歴単位の厳密検証

1,000履歴の58正付与履歴で、150-bin の中点近似ではなく、ヒストグラム化前の履歴エネルギーを比較する。隣接ビンにずれた3履歴をイベントID・停止時処理・境界で追跡する。

調整に使った seed は最終の独立検証に使用しない。

**合格：** 独立 seed の各加算、各履歴の原データに基づく比較が合格。フィット係数や境界条件ごとの手調整なし。

### Gate 4：空間分配・他物理過程

Pb-真空／異材質境界と voxel 分割の一致、電子 cutoff、光子の局所付与、陽電子停止・消滅、511 keV 光子を検証する。

PHITS タリーの代表座標と、連続輸送区間に沿うエネルギー付与分布を混同しない。区間の微視的分布が不明な場合は点として断定せず、区間または未解決として表現する。

**合格：** 独立タリーの領域別・voxel別エネルギーに加え、個々の計上位置・区間の根拠を示す。未解決の物理過程を隠さない。

### Gate 5：統合の判断

Linux/Windows双方の C++ コンパイル・テスト、固定条件と独立 seed の一致、HDF5出力の互換性と区間情報の明示、ストリーミング性能を確認してから PR #6 への統合を提案する。

**禁止：** PR #6 への直接変更、既存計算式の自動切替、強制正規化、異常入力の黙示修復、未確認物理の0置換、PHITSのライセンスに反する配布。

## 3. この最初のプッシュの範囲

- 実装計画
- 加算ID単位の独立検証ツール
- PHITS生データを使わない合成自動テスト

**含めない：** 未アップロードのローカル物理計算試作、停止能テーブル、PHITSソース、Dumpall、現行 converter のパーサ／deposit式の変更。

合成検証ツールの成功をPHITSの物理モデルの完成と誤記しない。
