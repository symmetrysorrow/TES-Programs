# TOML モデルとケースの構成

通常の入口は `cases/<実験名>.toml` です。１回の計算条件を１ファイルで固定し、`model = "single_pixel"` のように再利用する形状を指定します。モデルは `models/<モデル名>.toml` に置き、寸法・材料・TES の配置・メッシュ条件を定義します。

単ピクセルの基準と alpha 変更は別ケースですが、同じモデルとメッシュを参照します。PoST のケースは別モデルを参照します。既存の PoST を使うためにモデルを編集する必要はありません。

回路値の優先順位は、モデルの共通値 → モデル内の部品 → 配置グループ → ケース全体 → ケースの個別 TES です。`python main.py show <ケース名>` で展開後のモデル・位置・主要値を確認できます。形状とメッシュ設定が同じならメッシュを再利用し、定常条件が変わったら定常解を再計算します。

旧 JSON / TOML ケースは既存結果の再現用に残しています。４ TES のメッシュ・SIF・回路ライブラリ、および新形式の単ピクセル SIF 生成は確認済みです。全ソルバー計算と旧単ピクセル波形との数値比較は未実施です。
