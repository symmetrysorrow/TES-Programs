# ソース差分の適用範囲

`HeatSolve_generic_matc_node_cache.patch`は、基準コミットから外部Elmer診断sourceへPhase24計測と既存のdynamic conductivity処理を加えた一時treeに対する差分である。外部ソースの隔離DLL build用であり、このリポジトリの製品sourceやDLLには適用していない。

`Phase24 Dynamic K Node Cache`の既定値はFalse。Vector AssemblyをOFFにしたGeneric prism assemblyで使える。対象はMATC scalar string、依存変数Temperatureのみ、Lua/procedureなし、Heat Conductivity定義が単一の場合に限定する。判定不能な材料は従来Generic経路へfallbackする。対応表はmaterialごと・rankごとに構築し、mesh変更で破棄する。MATC値は各非線形assemblyで現在温度から再評価する。

行列/RHS/CSR挿入、時間積分、TES circuit処理は差分対象外。ValueList/MATC呼出しはrank内で逐次処理し、MPI rank間で値を共有しない。
