# TES 過渡 MPI 回帰基準

## 凍結基準

- 直接法時系列: `artifacts/series/tes_pulse_20ms_3x_series.csv`
- パルス時刻: 20.020 ms
- 基線窓: 19.500–20.020 ms
- 比較量: TES 温度、電流、抵抗、ジュール発熱

## 採択条件

MPI 版は、同じ入力・メッシュ・時間刻みで次をすべて満たす場合だけ採択する。

| 量 | 閾値 |
|---|---:|
| 基線電流差 | 1 % 以下 |
| パルス波高差 | 2 % 以下 |
| ピーク時刻差 | 10 µs 以下 |
| 比較窓内の最大電流差 | 直接法波高の 2 % 以下 |

## 実装順序

1. 各非線形反復で、時刻、反復番号、TES平均温度、前ステップ電流、電流、抵抗、未緩和電力、反復後電力を出力する。
2. 直説法とMPIで最初に異なる反復を検出する。
3. 初期化、前ステップ値の確定、温度平均の参照時点、Aitken残差の順に一致させる。
4. 回帰を通過してからCOMSOL比較と速度比較を行う。

数値反復のAitken更新は物理パラメータではなく、旧直説法と同一の非線形方程式を解くための収束手順として扱う。

## 2026-07-23 実装・検証状況

- `HeatSolve.F90` のMPI内蔵回路に、旧直接法と同じ初期化、
  `PreviousCurrent` のcommit、`IterInStep`、dt変更時のAitken再初期化、
  定常時の固定緩和を実装した。
- 通常系列は収束済み前ステップを出力し、反復診断は
  `TES Iteration Series File` に出力する。
- 凍結系列と同じ時間刻み、非線形最大反復数、収束許容誤差を使用する。
- `HeatSolve` が `Nonlinear System Min Iterations` を指定された場合に
  最低反復数を実際の終了判定へ反映するようにした。回帰ケース自体は
  直接法と同じ通常の収束判定を使う。
- 直列restartは `scripts/prep/partition_elmer_restart.py` でrank別restartへ
  変換できる。
- 非適合Mortar界面を一般のMetis分割で跨ぐと熱パルスがTESへ伝わらない。
  現在は検証済みの `mesh_refined_3x_repart_x` を使用する。
- 回路時定数より十分に粗い刻みが2掃引で収束し、未消費の温度掃引により
  境界CSVの電流だけが電気熱応答と逆向きになる場合は、2温度の中点で
  観測電流を再評価する。これは出力境界のpartition依存スパイクだけを除き、
  ジュール電力と次ステップの内部回路状態は変更しない。
