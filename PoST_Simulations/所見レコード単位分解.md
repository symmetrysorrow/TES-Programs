# レコード単位の低周波・高周波パワー分解：初見

作成日: 2026-09-05  
対象データ: `r1ch12_215mK_1400uA1400uA_difftrig5e-5_rate500k_samples100k_gain5_day2`  
対象チャンネル: CH0

## 1. 背景と目的

`PoST_Simulations` と `H:\hata\noise_fit` の比較では、概ね100 kHz付近以降で実験値がシミュレーションを上回る。

これまで、実験値とシミュレーションの差を平坦な白色残差床としてシミュレーションへ追加する方法を検討した。しかし、この方法は実験データから求めた値を経験的にシミュレーションへ埋め込むものであり、残差の物理的起源を説明しない。

そこで、追加の同条件測定なしに、1つの実験データ内のレコード間変動を使って、次の2種類の成分を分離できるかを調べた。

1. 低周波パワーに加法的に連動する高周波成分
2. 低周波パワーと無関係な高周波成分

## 2. 使用した処理

既存の高周波診断と同一の選別・処理を用いた。

- サンプル数: 100,000
- サンプリング周波数: 500 kHz
- DC除去: 各レコードの平均値を減算
- デジタルフィルタ: 2次Bessel、10 kHz、`filtfilt`
- 窓関数: Hann
- スペクトル: 片側PSD
- 受理条件: レコード長一致、raw peak-to-peak ≤ 0.04
- 受理レコード数: 345
- 長さ不一致: 29
- raw range超過: 55

解析スクリプト:

- [recordwise_decomposition.py](H:\hata\noise_fit\mid_high_fit\recordwise_decomposition.py)

## 3. 加法PSDモデル

まず、各レコードについて

\[
P_{i,\mathrm{high}}(f)=a(f)P_{i,\mathrm{low}}+b(f)
\]

を線形PSD上で評価した。ここで、(aP_{i,\mathrm{low}}) は低周波パワーに連動する成分、(b) は低周波パワーに依存しない切片候補である。

低周波の説明変数として、以下を比較した。

- 1–100 Hz raw PSD
- 1–100 Hz filtered PSD
- 1–10 kHz filtered PSD
- 1–30 kHz filtered PSD

### 結果

高周波帯は以下の4帯域に分けた。

- 100–120 kHz
- 120–175 kHz
- 185–215 kHz
- 225–249 kHz

すべての帯域で、加法PSDモデルの5分割ホールドアウト (R^2) は0以下となった。したがって、今回のデータでは、

\[
P_{\mathrm{high}}-aP_{\mathrm{low}}
\]

という形で低周波パワーに比例する成分を安定に推定することはできなかった。

これは、低周波パワーを使って高周波の残差床を単純に引く方法を支持しない。

## 4. 対数パワーによる乗法関係

次に、乗法的なレコード間変動を調べるため、

\[
\log_{10}P_{i,\mathrm{high}}
=
\gamma\log_{10}P_{i,\mathrm{low}}+c
\]

を評価した。

120 kHz以上の帯域では、1–10 kHzまたは1–30 kHzのfiltered PSDとの間に非常に強い対数相関が見られた。

代表的な指数は以下の通り。

| 高周波帯域 | 低周波指標 | γ | 対数空間の in-sample R² | 5分割CV R² |
|---|---:|---:|---:|---:|
| 100–120 kHz | 有効な予測関係なし | — | — | — |
| 120–175 kHz | 1–30 kHz filtered | 0.858 | 約0.9998 | 約0.114 |
| 185–215 kHz | 1–10 kHz filtered | 0.806 | 約0.9998 | 約0.044 |
| 225–249 kHz | 1–30 kHz filtered | 0.743 | 約0.9997 | 約0.144 |

in-sampleでは極めて強い関係が見えるが、ホールドアウト性能は限定的である。そのため、これを物理的な因果関係と断定することはできない。

現時点では、レコードごとの振幅・利得・全体ノイズレベルの変動が、高周波と低周波に共通して現れている可能性が考えられる。

## 5. レコード単位の乗法正規化

各レコードを低周波パワーの中央値へ合わせる補正を試した。

\[
P_{i,\mathrm{high}}^{\mathrm{corr}}(f)
=
P_{i,\mathrm{high}}(f)
\left(
\frac{P_{\mathrm{low,ref}}}{P_{i,\mathrm{low}}}
\right)^\gamma
\]

この補正により、レコード間の高周波パワー散らばりは大きく減少した。

| 高周波帯域 | 補正前の log10標準偏差 | 補正後 | 平均パワーの変化 |
|---|---:|---:|---:|
| 120–175 kHz | 1.91 | 0.027 | 約 -0.44 % |
| 185–215 kHz | 1.79 | 0.026 | 約 -0.38 % |
| 225–249 kHz | 1.65 | 0.030 | 約 -0.37 % |

### 解釈

この結果は、レコードごとの高周波変動の大部分が、低周波側の変動と共通した乗法的変動で整理できる可能性を示す。

しかし、平均スペクトルはほとんど変わらなかった。したがって、この補正はレコード間の散らばりを減らす効果はあるが、実験値とシミュレーションの平均的な高周波差を埋める方法にはなっていない。

## 6. 現時点での結論

現データに対する初見は以下の通り。

1. 高周波残差は、低周波パワーに単純に加法的に比例する成分としては検出できない。
2. 120 kHz以上では、低周波パワーと高周波パワーの間に強い乗法的関係がある。
3. その関係を使うとレコード間の散らばりは大きく減るが、平均高周波スペクトルはほとんど変わらない。
4. したがって、観測されている平均的な高周波残差床は、レコード間振幅変動だけでは説明できない。
5. 100–120 kHz付近の局所的な盛り上がりは、今回のレコード単位のモデルでは説明できない。
6. 白色残差床をシミュレーションへ追加する方法は、引き続き比較用の現象論的モデルであり、物理起源の説明ではない。

## 7. 現時点で可能な扱い

追加の同条件測定ができないという前提では、次の2つを区別して扱う必要がある。

### レコード間変動を除いたスペクトルを見たい場合

120 kHz以上について、低周波パワーを基準にした乗法正規化を適用できる。ただし、これは「低周波と高周波に共通する振幅変動を除いたスペクトル」であり、読み出しノイズ床を除去したスペクトルとは呼ばない。

### 検出器固有ノイズと比較したい場合

今回の解析結果だけでは、平均高周波残差を正当に除去できない。実験データから床を差し引く場合は、

\[
A_{\mathrm{corr}}(f)
=
\sqrt{\max\left[A_{\mathrm{exp}}^2(f)-A_{\mathrm{floor}}^2(f),0\right]}
\]

というPSD差し引きになるが、これは低周波側のシミュレーションモデルを正しいと仮定した条件付き補正である。
